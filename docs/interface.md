# 终端界面

终端界面保留 Neutral / Blue 配色和直角细边框；无颜色终端仍保留反色与焦点标记。下方 Dashboard 截图使用生产 `tui.TerminalUI` 的真实 curses 输出和演示数据，不含真实订阅令牌，也没有连接 VPS 或 Cloudflare。

## 正常首页

服务器与面板、节点与订阅分别显示。“已部署”依据本机记录，不代表实时检查云端资源。保留部署、订阅、维护和退出四个入口。

## 维护

维护操作收在二级页面，选中项高亮，下方显示用途。卸载和令牌轮换仍需要明确确认。

## 订阅

从首页直接查看普通订阅的完整导入地址，保留订阅名称、节点数量或动态优选说明。地址包含访问令牌，不出现在首页摘要中。

## 紧凑 Dashboard

最小 52×20 保留两条趋势与关键口径；`C` 可查看当前累计计数，`?` 查看说明。

![最小终端 Dashboard](images/tui-dashboard-52x20-new.png)

旧版仅域名配置仍会显示待处理提示，按 **A** 进入自动优选设置，确认后才更新 Worker。最初的设计归档见 [设计审阅板](../design/tui-shadcn/index.html)。
