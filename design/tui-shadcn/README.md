# PrivateXUI · 终端设计预览

**状态：已确认的设计稿归档。** 本目录保留最初供用户确认的独立预览与截图，使用演示数据。已确认的样式现已移植到生产 `tui.py`，后置出口与分组订阅见 [功能说明](../../docs/egress.md)。本目录的预览仍不调用真实业务。

保留 SSH 终端 TUI 的产品形态。参考 [shadcn 预设 b1Q5GC](https://ui.shadcn.com/create?preset=b1Q5GC&item=preview&template=vite)，将它的配色、组件层级和排版节奏转译为字符界面。

## 查看设计

在项目根目录运行：

```bash
python3 design/tui-shadcn/preview.py
```

仅需要支持 curses 的 Python 3.9+ 和 UTF-8 交互终端，不需要 root、pip、npm 或业务配置。推荐终端尺寸为 120 列 × 36 行，最小 52 列 × 20 行。

也可以直接打开 [静态审阅板](index.html)，查看由真实 curses 输出生成的截图；审阅板不启动 Web 服务。交互以终端预览为准。

```bash
# 从指定页面开始
python3 design/tui-shadcn/preview.py --screen dashboard
python3 design/tui-shadcn/preview.py --screen maintenance

# 如果当前 shell 设置了 NO_COLOR，单次使用彩色预览
env -u NO_COLOR python3 design/tui-shadcn/preview.py

# 查看无颜色回退
NO_COLOR=1 python3 design/tui-shadcn/preview.py
```

## 设计方向

| 参考设定 | 在终端中的表达 |
| --- | --- |
| Nova，紧凑布局 | 固定页头、内容分组、共享底部操作栏；根据终端尺寸收缩间距 |
| Neutral，中性色底色 | 深灰背景、亮灰正文、次级灰标签；以分隔线和留白组织信息 |
| Blue，蓝色强调 | 键盘焦点和主要操作使用蓝色；状态继续配合文字说明 |
| Radius None，无圆角 | 使用直角字符边框，不使用原界面的圆角大卡片 |
| Menu Accent Subtle | 列表只突出当前选中行；普通选项保持安静 |
| Chart Neutral | 上传、下载趋势采用灰度；通过独立标签、图例和单位区分 |
| IBM Plex Sans / Lucide | 终端保留用户等宽字体；不强制 Web 字体、不依赖图标字体 |

原始预设、官网 CSS 变量和亮 / 暗色截图保存在 [reference/](reference/)。真实终端使用标准 256 色近似，色彩会受终端能力影响；无颜色时仍保留焦点标记和状态文字。

## 页面与操作

设计包括首页、流量概览、热门域名、连接历史、维护、订阅、部署输入及危险操作确认。首页保留现有四个入口，Dashboard 保留原来的三页结构。

| 位置 | 按键 |
| --- | --- |
| 首页 | `1` 部署、`2` 订阅、`3` 维护、`4` 退出；方向键选择，Enter 打开 |
| 首页 | `D` 打开 Dashboard，`A` 打开优选设置预览 |
| Dashboard | `1 / 2 / 3` 切换概览、域名、历史；`← / →` 切换时段 |
| 列表 | `↑ / ↓` 移动或滚动，`/` 搜索历史 |
| Dashboard | `R` 刷新演示，`P` 暂停 / 恢复显示刷新 |
| Dashboard | `C` 查看当前累计计数；窄屏也可使用；`A` 打开入口设置 |
| 确认页 | `← / →` 选择返回 / 确认，长摘要使用 `↑ / ↓` 阅读全文 |
| 预览 | `S` 切换演示状态，`?` 查看帮助 |
| 返回 | `Esc / Q` 返回上层；首页退出 |

键盘输入页面中，普通字母用于输入文本；不要把全局快捷键理解为输入框中的命令。

## 设计边界

- 数据仅来自预览内的示例；部署域名使用 `example.com`，IP 使用文档示例网段；历史中的公共域名同样只是虚构连接记录。
- “已部署”保留“本机记录”语义，不表示云端实时检查成功。
- “近两分钟均速”、域名“连接记录数”、3x-ui“当前累计计数”分别保留原有口径。
- 缺采样、等待采样、无连接、无日志与采集异常有不同文案；图表缺口不伪装成零值。
- 所有确认只演示界面反馈，不执行安装、更新、令牌轮换、卸载或采集管理。
- 订阅页展示占位地址，供查看设计；不伪造剪贴板成功提示。
- 本目录不读真实凭据、状态文件或数据库，不连接 Cloudflare，不调用 systemd，不启动网络监听。

这是界面设计预览，不是完整业务实现。刷新与检查展示固定演示数据；输入仅演示基本的必填反馈。订阅名称修改等已有配置流程，在最终移植时沿用原项目校验与确认逻辑。示例时间固定为 2026-10-07，便于逐张对照。

原设计阶段的独立审核与验证记录见 [design-qa.md](design-qa.md)，其中的源码哈希指向本目录内的独立预览，不是后续生产实现。
